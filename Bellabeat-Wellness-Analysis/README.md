Bellabeat Wellness Analysis

Project Overview
This case study analyzes smart device usage data to uncover patterns in daily activity and sleep behavior for Bellabeat, a women-focused wellness technology company. The goal is to translate user behavior into actionable marketing and product recommendations.

Business Objective
To identify how users engage with activity and sleep tracking features and uncover opportunities to improve user engagement and feature adoption for Bellabeat.

Key Questions
- How do daily activity levels vary across users?
- What is the relationship between activity and calories burned?
- How consistent is sleep tracking behavior among users?

Tools Used
- SQL (BigQuery) – data cleaning and analysis  
- Tableau – dashboard and data storytelling  
- GitHub – documentation and portfolio hosting  

Key Insights
- Users show relatively consistent daily activity patterns.
- Higher activity levels are associated with higher calorie burn.
- Sleep duration is stable among users, but sleep tracking engagement is lower.

Business Recommendations
- Link activity and sleep insights to promote holistic wellness.
- Increase engagement with sleep tracking through reminders and in-app nudges.
- Use personalized insights to promote premium wellness features.

 Data Source
Fitbit Fitness Tracker Dataset (Kaggle)
